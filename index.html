      About that starfield

      …

      The stars drifting behind the title, and the satellites orbiting through them, are not a CSS animation. They are true Newtonian orbits integrated every frame by a WebAssembly module that was hand-assembled byte by byte — LEB128 section headers, opcode by opcode — with no compiler and no toolchain anywhere in the loop. It is 780 bytes, embedded directly in the page, so the front door has nothing to download and nothing that can fail. Velocities are solved from v = √(GM/r); there is not a single trigonometric function in it.

      Motion Lab — an educational biomechanics explorer. Built for public understanding of movement science, not clinical diagnosis.
